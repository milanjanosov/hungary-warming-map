# Magyarország melegedési térképe

Interaktív térkép: a nyári felszínhőmérséklet változása 2004–2008 és 2022–2026 között (Landsat 5–9),
járásonként és Budapestre, KSH népességgel. Felszíni hőmérséklet, nem léghőmérséklet; a térkép azt mutatja
meg, hol melegedett jobban, nem azt, hogy pontosan hány fokkal (két ötnyári kompozit különbsége).

A pöttyök a tíz legnagyobb város leggyorsabban melegedő foltjai; az ok-címkék automatikusak és tájékoztató
jellegűek (szúrópróbán nagyjából fele–kétharmaduk helytálló).
